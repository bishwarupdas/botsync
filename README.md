# Botsync case: interactive fleet walkthrough

## Open it (no install, works offline)

```bash
git clone -b walkthrough-build https://github.com/bishwarupdas/botsync.git
```

Then open the folder `botsync/botsync_walkthrough/` and double-click **`index.html`**. It opens in Chrome, Edge, Firefox or Safari. Nothing to install, no server, no internet needed.

(No git? On GitHub, click **Code → Download ZIP**, unzip it, and double-click `botsync_walkthrough/index.html`.)

## What is in this repository

| Path | What it is |
|---|---|
| `botsync_walkthrough/` | **The interactive walkthrough.** Double-click `index.html`. |
| `case_documents/` | The written case (PDF), the dummy-data workbook and the script that generated it. |
| `botsync_walkthrough.zip` | The same walkthrough as a single zip file. |
| `source/` | The build brief and the workbook the page was built from. |
| `WALKTHROUGH.md` | Build notes and every interpretation choice. |
| `SPEC_CHECKLIST.md` | The brief, section by section, with where each part is and how it is tested. |
| `evidence/` | Test output and screenshots from the last run. |
| `tools/` | Build and test scripts (not needed to view the page). |

Dummy data: patterns are seeded on purpose, as the case asks. Model steps are scripted examples, not live model calls.
